## 소개

- 이름: DJlee
- 과정: AI 프로덕트 매니저 (2026.10 ~ 2027.04)
- 목표: 사용자 문제를 이해하고, 데이터를 기반으로 서비스를 설계하며, AI를 활용해 실제 가치를 만드는 사람
- 관심 분야: 서비스 기획, 유저 여정, 데이터 기반 의사결정, AI 서비스 설계, 제품 실험

## 나는 이런 사람입니다

사용자에게 더 좋은 경험을 주는 서비스를 만드는 것에 관심이 많습니다. 제품을 기획할 때 단순히 기능을 추가하는 수준을 넘어서, 어떤 문제를 해결해야 하는지 정의하고, 그 문제를 데이터와 AI를 활용해 실질적인 해결책으로 연결하는 데 집중합니다.

## 프로젝트 방향

- 사용자 문제를 명확하게 정의하고 가설을 세우기
- 데이터를 기반으로 핵심 지표를 설계하고 검증하기
- AI 기능을 제품에 자연스럽게 녹여 사용자 경험을 개선하기
- 실험과 피드백을 반복하며 제품을 성장시키기

## 핵심 가치

- 사용자 중심 사고
- 데이터 기반 의사결정
- 협업과 커뮤니케이션
- 빠른 실험과 반복
- AI를 활용한 문제 해결

## 핵심 역량

| 역량 | 설명 |
| --- | --- |
| 사용자 리서치 | 실제 사용자 문제를 발견하고 니즈와 불편을 정리하는 역량 |
| 서비스 기획 | 사용자 문제를 해결할 수 있는 서비스 방향과 기능을 설계하는 역량 |
| 제품 실험 설계 | 가설 검증을 위한 실험 구조와 핵심 지표를 설계하는 역량 |
| 데이터 기반 의사결정 | 데이터를 해석해 인사이트를 도출하고 의사결정에 반영하는 역량 |
| AI 서비스 설계 | AI 기능을 제품에 적절히 연결해 사용자 가치를 만드는 역량 |
| UX / 서비스 설계 | 사용자 여정과 경험 흐름을 개선해 더 나은 서비스를 만드는 역량 |
