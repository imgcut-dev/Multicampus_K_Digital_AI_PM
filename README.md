### 나는 이런 사람입니다

사용자에게 더 좋은 경험을 주는 서비스를 만드는 것에 관심이 많습니다. 제품을 기획할 때 단순히 기능을 추가하는 수준을 넘어서, 어떤 문제를 해결하고 어떤 가치가 실제로 전달되는지를 생각합니다. AI 시대에는 기술 자체보다 “어떻게 사람의 문제를 해결할 수 있는가”가 더 중요하다고 믿습니다.

### 프로젝트 방향

- 사용자 문제를 명확하게 정의하고 가설을 세우기
- 데이터를 기반으로 핵심 지표를 설계하고 검증하기
- AI 기능을 제품에 자연스럽게 녹여 사용자 경험을 개선하기
- 실험과 피드백을 반복하며 제품을 성장시키기

### 핵심 가치

- 사용자 중심 사고
- 데이터 기반 의사결정
- 협업과 커뮤니케이션
- 빠른 실험과 반복
- AI를 활용한 문제 해결
